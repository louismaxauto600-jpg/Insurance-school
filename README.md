Installation
Open the Insurance School repository on GitHub.
Upload index.html.
Upload insurance-school-logo-animated.mp4.
Upload README.md.
Confirm that all three files appear in the repository root.
Commit the changes.
No separate CSS or JavaScript files are required. All page styling and functionality are included inside index.html.
Deployment
The project is a static website and can be deployed directly through GitHub Pages, Netlify or the main BSS1815 PRO-MAX DMP hosting configuration.
For the central platform, the intended public path is:
/insurance-school/
The server must publish this folder with its own index.html and animated logo video in the same directory.
